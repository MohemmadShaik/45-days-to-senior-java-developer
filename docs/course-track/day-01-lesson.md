
# Day 1 – Core Java OOP Fundamentals

## Learning Outcomes
Understand and apply:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Constructors
- Overloading and overriding
- Composition and loose coupling
- Dependency inversion

## Teaching Format
For every concept:
1. Clear explanation.
2. Maximum three real-world scenarios.
3. Puzzle-based technical questions.
4. Java coding demonstration.
5. Common mistakes and interview traps.
6. Practical implementation.

## Real-World Scenarios
1. Banking – BankAccount and balance validation.
2. Payment processing – UPI, Card and Net Banking.
3. Employee management – Employee and Manager.

## Mini Project
Payment Management System

## Functional Requirements
- Payment interface.
- UPI, Card and Net Banking implementations.
- PaymentService with constructor injection.
- Encapsulated BankAccount.
- Employee and Manager inheritance.
- Notification interface with default method.
- Method overloading demonstration.
- Exception handling.
- JUnit 5 tests.

## Interview Assessment
- 15 MCQs.
- Practical coding assignment.
- Design explanation.
- Edge-case testing.
- Code review.
